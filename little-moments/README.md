# Little Moments

A course prototype for personalized, scenario-based caregiver learning.

## Open the app

Open `index.html` in a browser. Start with **For parents**, choose **Use Taeha sample**, and open **Caregiver view** to try three scenarios. You can also create a profile and copy an invitation for the caregiver entry screen.

## Implementation

One HTML file contains semantic HTML, CSS, and JavaScript. Profile information is saved in the browser's local storage. Scenarios use predefined rules; they are not AI-generated.

Invitations contain a snapshot of the saved profile, excluding photos. They are not encrypted or password protected. Share only fictional information for classroom demonstrations. No real profile or photo is included in this repository.

## AI assistance

ChatGPT/Codex assisted with layout planning, HTML/CSS, JavaScript interactions, and debugging. The student supplied the concept and paper sketch and directed iterative design revisions.
